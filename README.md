## 🔐 Security & Compliance

We follow industry-standard practices for security, including:
- Cloudflare edge security (WAF, DDoS protection, managed rules)
- Encryption in transit and at rest
- Minimal data collection
- Firebase App Check and reCAPTCHA Enterprise for abuse prevention
- Mint authority and freeze authority revoked (fixed supply enforcement)
- Stripe PCI-DSS compliant payment verification

See the SOC 2 Alignment Report for a complete control inventory.
